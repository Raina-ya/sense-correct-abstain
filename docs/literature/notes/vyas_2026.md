## What is actually proved

Let the compiler draw a sign vector `s` from a known distribution `pi(s)` that
does not depend on the coherent parameters `theta`. A shot produces outcome
`b` with conditional probability `P(b | s, theta)`. Therefore

```text
P(b, s | theta) = pi(s) P(b | s, theta).
```

The score of the joint experiment equals the conditional score because
`partial_theta log pi(s) = 0`. Thus

```text
F_joint = E_s[F(b | s, theta)] = F_cond.
```

Factoring the same joint distribution as
`Pbar(b | theta) P(s | b, theta)` gives the Fisher chain rule

```text
F_cond = F_marg + Delta,
Delta = E_b[F(s | b, theta)] >= 0.
```

This identity is valid for any correctly specified conditional likelihood with
parameter-independent label sampling. It says how much information is lost by
discarding the label. It does **not** say that a particular physical error must
enter the likelihood with a label-dependent sign.

## Single-qubit recovery model

The paper's explicit example assumes a coherent error

```text
exp(-i s theta G / 2),  s in {-1,+1},
```

where Pauli conjugation flips the generator's sign. For a `Z` error on `|+>`
measured in the `Y` basis,

```text
P(b | s, theta) = (1 + b s sin(theta)) / 2.
```

At a fixed sign the classical Fisher information is one. Under a balanced
twirl, the marginal first-order signal vanishes while the joint labeled data
retain it. With a noisy conditional mean

```text
E[b | s] = v s sin(theta) + o,
```

the balanced correlation removes the label-independent offset:

```text
E[s b] = v sin(theta).
```

If `v` is known, the proposed estimator is

```text
theta_hat = arcsin(E[s b] / v).
```

## Oracle and nuisance audit

| Quantity | How the paper treats it | Deployability issue for this project |
|---|---|---|
| Label `s` | Known compiler output, recorded per cycle/shot. | Deployable if the execution stack preserves the exact absorbed-frame label. |
| Outcome `b` | Measured bit/quadrature outcome. | Deployable, but the QAOA energy/gap measurement is not automatically the paper's `Y`-quadrature probe. |
| Label law `pi(s)` | Chosen by the compiler and independent of `theta`. | Must remain independent of `epsilon`, graph, candidate outcome, and adaptive decisions used in the same estimation stage. |
| Generator and sign action | Assumed known: conjugation maps the same error generator to `s G`. | **Model-match condition.** It must be derived for logical-angle E2; frame algebra for the ideal gate is insufficient. |
| Visibility `v` | Described as available from Pauli fidelities/cycle benchmarking or fitted from the same run. | If only `E[sb]` is observed and `v` is otherwise unknown, the data identify `v sin(theta)`, not `theta`. The exact source, cost, and uncertainty of `v` must be charged. A separate cycle-benchmarking product is not literally free merely because it is part of an RC workflow. |
| Offset `o` | Removed by a balanced label correlation. | Only label-independent offsets cancel. Label-dependent SPAM or control errors require a larger nuisance model. |
| Ideal response/finite-difference response | The general simulation section mentions a finite-difference probe used to compute a response; the paper does not provide enough detail in the main text to certify that arbitrary-circuit recovery is target-oracle-free. | QAOA Gate 1A may not use an ideal target response, an injected true angle, or a simulator-derived derivative in its pass statistic. |
| Injected hardware phase | Known by construction; hardware validation deliberately injects virtual `RZ(s theta*)`. | This is a positive control for the sign-label mechanism, not evidence that an unknown physical QAOA over-rotation obeys the same model. |
| Multiple-location response | Uses `F_cond = mathcal F Hadamard Sigma`; rank depends on response geometry and label correlations. | `mathcal F` cannot be assumed known from an ideal simulator for the deployable pass criterion. Shared labels may identify only combinations. |

## Parameter mapping between the paper and this project (added 2026-11-20)

| Paper | Project | Why |
|---|---|---|
| `theta` in `exp(-i s theta G / 2)` | `phi` (additive, gate-independent phase) | Its sign follows the label because the error is fixed after the gate and the frame conjugates the generator. |
| no counterpart in the explicit example | `epsilon` (angle-proportional) | The angle-proportional term rides on the commanded angle, which the label also flips, so the two flips cancel in the logical frame (frame-covariance draft). |
| visibility `v` (known-response probe) | slope of the unknown target response `dF_r/du` | In a QAOA target the factor that multiplies the label contrast is a property of the unknown ideal response, not a separately benchmarked visibility. |

So the paper's positive result, read through this mapping, concerns the
project's `phi`, not `epsilon`. This is an interpretation of the agent's
full-text reading and must be confirmed against the paper.

## Testability versus estimability in a QAOA target (added 2026-11-20)

Under the compiled-angle, virtual-Z model, label `s` yields
`F_r((1+epsilon)theta + s phi)` with `F_r` the unknown target response.

1. **A deployable test exists for `phi != 0`.** Under `phi = 0` every
   label-contrast statistic has mean zero for every response `F_r`, so a
   contrast-based alarm has a known null distribution without any ideal value.
2. **Estimating `phi` is not deployable from target labels alone.** The contrast
   mean is approximately `2 phi F_r'(u)`; without the slope `F_r'(u)` (ideal
   response information), only the product is identified. This is the QAOA
   analogue of the paper's need for `v`.
3. **For `epsilon` neither holds at `phi = 0`.** The contrast is identically
   zero, so there is no test and no estimate.

Consequence for the project: RC labels may support an alarm-and-abstain action
(the Chapter 2 pattern) for additive errors, but not a correction action, which
needs an estimate. This sharpens Gate 2: Gate 1A could be passed for `phi` and
still give no deployable correction. These are draft statements to be derived
formally in Part 1.

## Direct comparison with the current E2 model

The current frame-covariance draft represents the absorbed-label phase as

```text
alpha_s(theta, epsilon, phi) = (1 + epsilon) theta + s phi.
```

Under that model,

```text
partial_epsilon alpha_s = theta,
partial_phi     alpha_s = s.
```

The `epsilon` direction is label invariant; the `phi` direction changes sign.
At `phi = 0`, a balanced label contrast is therefore predicted to have zero
first-order sensitivity to `epsilon`, even though absolute outcomes can depend
on `(1+epsilon)theta`. Absolute-level Fisher information can be full rank when
an ideal response is known, but that is not deployable label information.

This is not a contradiction of Vyas. It means the project likelihood is not
the paper's `s theta` likelihood for the parameter `epsilon`. Gate 1A must
derive the implemented likelihood and then compute:

1. Fisher information from label contrasts alone;
2. Fisher information from absolute levels with a known ideal response;
3. efficient/profile information for `epsilon` when the ideal response and
   visibility are nuisance quantities.

Only items 1 and the non-oracle remainder of item 3 may pass Gate 1A.

## Claims that may and may not be carried forward

Safe with attribution:

- retaining labels can preserve information discarded by marginalization when
  the conditional likelihood is label dependent;
- label design and correlations affect identifiable parameter combinations;
- an injected virtual phase obeying the paper's sign model was recovered in a
  hardware positive control.

Not established for this project:

- that logical-angle multiplicative E2 is label identifiable;
- that the needed visibility/response is available at zero charged cost;
- that QAOA candidate-gap bias follows from coherent-angle recovery;
- that a full-rank Fisher matrix computed with ideal QAOA probabilities is a
  deployable Gate 1 success.
