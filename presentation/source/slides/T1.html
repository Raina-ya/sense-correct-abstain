The risk identity

Theorem T1 · three-action risk identity

Proof idea

Given X = x the private randomisation is independent of the stage-2 outcome, so path C contributes πC(x)·lC; the tower property gives the first line and πN = 1 − πC − πA the second. No independence between sensor and target data is needed.

Read the second line as: baseline issue risk, plus what switching to C or A gains or loses.

T1 是整個理論的基礎：風險等於基準的發答案風險 q，加上切換到 C 和切換到 A 各自帶來的增減。證明只用到 tower property 和私有隨機性的獨立性，不需要感測資料和目標資料獨立。
