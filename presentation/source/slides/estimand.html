Failure analysis

Frozen versus corrected estimand

The frozen runner scored the N path as P(N)·q; the true expected loss is P(N ∩ W), with W = {issued answer wrong}.

Sign

N is chosen only when the observed gap is large — computed from the same shots as δ₀ — so the issued answer is less often wrong: Cov ≤ 0, and the frozen N loss is biased upward.

Size

Mean N loss 0.00278 (frozen) vs 0.00218 (realised) on 919 units. The correction raises ΔV by 0.000156 but leaves its lower bound negative.

凍結估計量的偏誤：凍結的程式把 N 路徑的損失算成 P(N)·q，但真正的是 P(N∩W)，差就是負的共變異數。因為策略只在觀察到的 gap 大時才選 N，而大 gap 時答案比較少錯，所以共變異數非正、凍結的估計偏高。修正後 ΔV 提高 0.000156，但下界仍為負。
