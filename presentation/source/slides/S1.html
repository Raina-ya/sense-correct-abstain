Lemma S1′ · at any true point with φ₀ = 0

  • (1) under N-q, hence N-loc:  I ⊇ (ε₀ − δ, ε₀ + δ) with δ = m/V > 0
  • (2) under N-loc:  I = ℝ
  • (3) under N-free:  I = ℝ
  • (4) if each Rc is differentiable, under all three classes the ε-score lies in the nuisance tangent set: the efficient information for ε is 0
S1′ 是 Gate 1A 的核心定理：φ=0 時，在 N-q 下 ε 局部不可識別；在 N-loc 和 N-free 下整條實數線都在識別集裡；三種類別下有效資訊都是零。
