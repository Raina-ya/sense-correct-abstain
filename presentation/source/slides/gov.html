Governance defects

  • The Gate 1A runner wrote its verdict, I3 ranks, recovery and control statuses as literals.
  • Analysis code was outside every lock.
  • Power was computed in the same execution as the evaluation: no point at which the design could have been revised.
  • Locks say “owner-approved” without review notes; lock-to-run intervals were 2–34 minutes.
  • Selection probabilities used 256 Monte Carlo replicates although exact values were computable.
  • Gate 4 thresholds were not power-derived; 25.7% of Gate 2 units were exact ideal-gap ties, not prescreened.

None changes a verdict; each limits what the locks prove. All are documented in append-only errata.

治理缺陷：六項，沒有一項改變判決，但每一項都限制了鎖定能證明的東西。誠實列出來比隱藏好，全部都記錄在 append-only 的勘誤中。
