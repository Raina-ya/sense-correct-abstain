Locks and the evidence boundary

Locks

Each gate’s design was committed with a SHA-256 manifest before its run; the runner refused to run unless the repository was at the lock commit.

Internal Git and SHA-256 locks, no independent timestamp: prespecified, not preregistered. Analysis code was not itself locked.

Evidence boundary

2–6 qubits, QAOA depth one, shot noise only. Quantities computed after a gate result are labelled post-lock: they can qualify a verdict but cannot change it.

Gates 3–4 comparator and power

Clusters 0–32 used once to select the comparator and estimate power; lower bound = 5th percentile of 10,000 cluster-bootstrap means of the 66 cluster means.

Scoring

Multinomial shots (NumPy PCG64), seeds from SHA-256 unit keys; action losses are 256-replicate Monte Carlo estimates used for scoring only.

證據邊界與鎖定：每個關卡事前用 SHA-256 鎖定，但只是內部 Git 鎖、沒有獨立時間戳，所以稱為「預先指定」而不是「預註冊」。分析程式碼本身沒鎖。事後計算的量都標記 post-lock，只能補充說明、不能改變判決。
